# AA Scope — LZ1RVD

Програма за Mac за антенния анализатор EU1KY (фърмуер r11), свързан през ST-LINK.
AntScope2 и NanoVNA-Saver не виждат порта на ST-LINK, затова е направена тази програма.

## Пускане
- Двоен клик на **AA Scope.app** (има копие и на бюрото). Отваря страницата в браузъра.
- Анализаторът трябва да е включен, в **главното меню**, свързан през USB на ST-LINK.
- Спиране: бутон **„Спри програмата“** на страницата.

## Какво прави
- Говори с анализатора само с командите на AA-600: `ver`, `fq`, `sw`, `frx`, `off` (само мерят).
- Открива горната граница на уреда (BAND_FMAX) с `fq` и не мери над нея (там уредът дава фалшиви 50 Ω).
- Графики КСВ, R/X, |Z|, Return loss, диаграма на Смит, лента при КСВ ≤ 1.5 / 2, сравнение на две измервания.
- Запис `.s1p` (Touchstone) и `.csv` в Downloads.

## Файлове
- `aa_scope.py` — локален сървър на 127.0.0.1:8765 (само Python от macOS, без външни библиотеки).
- `index.html` — страницата.
- `launcher.applescript` — изходен код на AA Scope.app. Ново приложение:
  `osacompile -o "AA Scope.app" launcher.applescript`
- `aa_scope.log` — лог (не е в git).

## Настройки
- Сериен порт: първият `/dev/cu.usbmodem*`, или `AA_PORT=/dev/... python3 aa_scope.py`.
- Скорост: 38400 (COM_SPEED на анализатора).
